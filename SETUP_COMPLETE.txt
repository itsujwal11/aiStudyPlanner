TROUBLESHOOTING:
================================================================================

If backend stops:
  cd C:\Users\Ujwal\Desktop\aiStudyPlanner\backend
  mvn spring-boot:run

If frontend stops:
  cd C:\Users\Ujwal\Desktop\aiStudyPlanner\frontend
  npm run dev

If database connection fails:
  lsnrctl status
  (Check if listener is running and xepdb1 service is registered)

If port is already in use:
  Backend (8080):  netstat -ano | findstr :8080
  Frontend (3001): netstat -ano | findstr :3001
  Then kill the process: taskkill /PID <PID> /F

If CORS error persists:
  - Clear browser cache (Ctrl+Shift+Delete)
  - Hard refresh (Ctrl+Shift+R)
  - Check that backend is running on port 8080
  - Verify frontend is on localhost:3001 (not 127.0.0.1)
